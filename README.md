# LandShareCalculator

Educational Android app for learning traditional Bengali land-share units.

Final UI and calculation rules:
- Ana selector: 1–15
- Gonda selector: 1–19
- Kora selector: 1–3
- Kranti selector: 1–2
- Til selector: 1–19
- 16 ana = 1 whole
- 20 gonda = 1 ana
- 4 kora = 1 gonda
- 3 kranti = 1 kora
- 20 til = 1 kranti

The main UI uses Kalpurush Bengali font. Developer credit uses Android default Roboto.
